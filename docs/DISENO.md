# Diseño y experiencia de usuario

**Versión:** 0.1 · **Estado:** criterios iniciales

## 1. Objetivo
Una aplicación moderna, clara y agradable que ayude a aprender. La experiencia debe sentirse como una herramienta educativa bien construida, no como una página publicitaria ni como un juego infantil.

## 2. Dispositivos
- Diseñar primero para celular sin descuidar computadora.
- Controles cómodos para pantalla táctil.
- Texto legible, contraste suficiente y jerarquía visual.
- Evitar pantallas saturadas y desplazamientos innecesarios.
- Mantener navegación consistente.

## 3. Lenguaje visual
- Profesional, actual, simple y cercano.
- Uso moderado del color para orientar y distinguir estados.
- Fotografías reales y útiles de productos, superficies, herramientas y resultados.
- Evitar decoración que compita con el contenido.
- Mantener consistencia entre cursos y módulos.

## 4. Experiencia del estudiante
La navegación debe permitir reconocer con facilidad:
- dónde está;
- qué está aprendiendo;
- qué completó;
- qué actividad sigue;
- qué necesita repasar;
- cómo volver al curso.

El progreso y los logros deben motivar sin convertir el aprendizaje en una competencia vacía.

## 5. Experiencia administrativa
El panel debe permitir organizar cursos, módulos, unidades, lecciones, imágenes, recursos, actividades y evaluaciones. Debe incluir borradores, vista previa y publicación controlada.

La edición de contenido habitual no debe requerir tocar código.

## 6. Accesibilidad y contenido
- No depender únicamente del color para comunicar.
- Añadir texto alternativo a imágenes educativas.
- Subtitular o transcribir recursos audiovisuales relevantes.
- Usar instrucciones claras y consistentes.
- Diferenciar información técnica, advertencias y ejemplos comerciales.

## 7. Pendiente
La identidad gráfica final, tipografías, paleta y componentes se decidirán con un prototipo navegable y pruebas con usuarios.
